# Production Evidence Profile: Cluster Soak

This report is generated by `scripts/verify_cluster_soak.sh`; it is intentionally
versioned by commit, host, OTP, topology, workload, and iteration count. It is
not a portable latency or availability guarantee.

## Required profile

- **Topology:** three separately named BEAM nodes; one leader and two followers.
- **Transport:** mutual TLS distribution with certificate and membership checks.
- **Workload:** deterministic command replication, follower redirect, commit
  visibility, crash/restart, disk-fault, reordered RPC, fencing, projection,
  index, and status checks.
- **Soak:** repeat the complete gate with `AARONDB_SOAK_ITERATIONS`; default 5.
- **Artifacts:** each iteration keeps its command log and deterministic seed
  under the configured artifact directory.

## Gates

A profile is admissible only when every iteration passes the format, type-check,
full test suite, deterministic fault corpus, TLS cluster proof, and diff-hygiene
checks. A future release may add numeric p50/p95/p99, throughput, lag, resource,
rebuild, and recovery thresholds; no universal numbers are invented here.

A sustained run must also record external process RSS/disk/queue samples when
used for promotion. The current local gate proves bounded harness execution and
correctness across repeated failover/recovery runs; it does not claim capacity
or production SLO compliance by itself.
